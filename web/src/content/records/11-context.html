# Sessions ## Overview Sessions message each other through `session-relay`, which turns an id into an address when it sends. ## Layout - `claude/skills/session-relay/`: the send and its header- `src/sessions/`: the roster each send reads ## Gotchas - A session reached through Remote Control writes no local record, so the roster misses it

Sessions

Overview

Sessions message each other through session-relay, which turns an id into an address when it sends.

Layout

  • claude/skills/session-relay/: the send and its header
  • src/sessions/: the roster each send reads

Gotchas

  • A session reached through Remote Control writes no local record, so the roster misses it
