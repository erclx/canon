Alpha element

Lesson 1. A deliberately meaningless lesson that carries one of every prose element the shell can draw.

Assumes: nothing, since nothing here is about anything.
Covers: headings, lists, a step list, a code block, a table, a callout and a cited claim.
Sources: none real, cited at the foot only to draw the reference list.

A section heading

A paragraph sits under a heading and runs long enough to wrap, so the measure and the line height both show. It says nothing on purpose, since a subject anybody would read is a subject that gets edited instead of the shell.1 Inline emphasis, strong text and inline code all sit inside it.

Retrieval check

1. Which element carries the one sentence to memorize?

Correct: the callout. The lede is the opening dek, the table lays out rows, and the code block holds a listing. Only the callout is set apart to hold a single line.

2. What does the step list carry under each step?

Correct: a line the learner could say. A step holds a sentence of explanation and a spoken line. A quiz, a footnote and a table row each live in their own element.

3. What is this lesson about?

Correct: nothing on purpose. The content is meaningless by design, so the shell is what gets developed rather than the words inside it.
