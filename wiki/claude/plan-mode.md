# Claude Code plan mode

Plan mode tells Claude to research and propose changes without executing them, so the whole approach is visible before anything changes. It is one of Claude Code's permission modes, entered with `Shift+Tab`, `/plan`, or `--permission-mode plan`. Source: [Choose a permission mode](https://code.claude.com/docs/en/permission-modes.md), which has no separate plan mode page.
