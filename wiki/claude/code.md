# Claude Code

Claude Code is Anthropic's CLI for Claude. It runs as an interactive agent in the terminal, reads a project through `CLAUDE.md`, and executes tasks with built-in tools. Source: [CLI reference](https://code.claude.com/docs/en/cli-reference.md), which lists every command and flag.

## Feature pages

- [Commands](commands.md): built-in slash commands
- [MCP](mcp.md): server configuration, scopes, and authentication
- [Hooks](hooks.md): event hooks and behavior control
- [Memory](memory.md): `CLAUDE.md`, auto-memory, and rules files
- [Skills](skills.md): skills, plugins, and installation
- [Plan mode](plan-mode.md): read-only exploration and plan approval
- [Permissions](permissions.md): modes, rules, and rule syntax
