# Claude Code commands

Slash commands control Claude Code from inside a session: switching models, managing permissions, clearing context, running a workflow. A command is recognized only at the start of a message, and skills bundled with Claude Code appear alongside the built-ins. Some commands depend on plan, platform, or environment. Source: [Commands](https://code.claude.com/docs/en/commands.md), which lists every command and what it does.
