# Claude Code routines

A routine is a saved Claude Code configuration that runs autonomously on Anthropic-managed cloud infrastructure, so runs continue when the laptop is closed. It bundles a prompt, repositories, an environment, and connectors, and starts from a schedule, an API call, or a GitHub event. Routines are a research preview, and `/loop`, Desktop scheduled tasks, and GitHub Actions are different features. Source: [Automate work with routines](https://code.claude.com/docs/en/routines.md).
