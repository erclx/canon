# Canvas standards

## Frames

- Load the `canon:canvas-board` skill before drawing or editing a frame. It carries the house style for an explanation frame and the content format. Report it rather than proceeding silently when the skill does not resolve.
- Write explanation frame text in sentence case. A mockup of the project's interface follows its design document instead.
- Size each explanation frame's box to show all its content with no scrollbar.
