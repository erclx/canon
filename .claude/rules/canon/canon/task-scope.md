# Tasks standards

## Task files

- Only create a task for work that spans multiple sessions or has real dependencies. Handle small edits immediately without a task entry.
- Do not add tasks retroactively for work already completed. Completed work is visible in git.
- Write a plan in `.canon/plans/` when a task needs execution detail beyond its own file, and link it from the task's intro paragraph.
- Write that plan in the same session as the task, since the executing session would otherwise re-derive the reasoning behind it.
