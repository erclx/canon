# Internal docs requirement

## Gap

Without this skill, a session lands internal narrative in `docs/` where consumer-facing reference belongs, or consumer reference in `canon/context/`, and hand-edits a generated index that the next check overwrites.

The routing failure is the one with no local symptom. A misplaced document reads correctly where it sits, and the cost arrives later, when a target project reads prose written for this repository or a session searches the tier that does not hold the answer.

## Must

- Route a document by its reader before writing it, keeping `docs/` for consumer-facing reference and sending internal narrative to `canon/context/`

## Must not

- Hand-edit a generated index

## Guards

- An `index.md` under `docs/` or `canon/context/` is generated by `canon indexes regen`. Fix the frontmatter of the file it lists rather than the index.

## Out of scope

- Word choice, punctuation, and formatting, which `claude/skills/markdown-craft/references/markdown.md` states directly, and voice and rhythm, which the `write-human` skill carries. Read those rather than loading this skill to reach them.
- The content of a Claude context entry that a plugin or skill change dates, which `internal-claude` updates. This skill owns the entry's shape through `claude/skills/context-fold/references/context.md`.
- A shape reference under a skill's `references/`, which `internal-claude` covers under `claude/skills/`.
- A wiki page under `wiki/`, which `claude/skills/draft-doc/references/wiki.md` governs.
