# Internal shipped reference requirement

## Gap

Without this skill, a `.claude/context/<name>.md` token in a shipped-corpus edit ships unreviewed either way it reads. `src/shipped/references.ts` classifies a pull request number, a commit sha, a resolvable `docs/` path, and a phase label by pattern, and its own `DOCS_PATH` doc comment states that this fifth form has no equivalent pattern: telling a citation of this repository's own domain entry apart from an illustration of a target's generic tree needs the sentence read, not matched. The same gap covers a layout, stack, or config-path claim stated as portable when it is true of this checkout alone.

## Must

- Read every `.claude/context/<name>.md` token in the diff's added or changed lines under `598-authoring-layout.md`'s eight corpora, and classify each against the checkout-only read the mechanical gate cannot make
- Read every layout, stack, or config-path claim in the same diff for whether it names a portable convention or a fact true of this checkout alone
- Report a finding as `<file>:<line>`, which half of the discriminator it failed, and a repair from the menu
- Report a clean pass rather than staying silent, so a reviewer sees the skill ran

## Must not

- Reclassify a pull request number, a commit sha, a resolvable `docs/` path, or a phase label. Those four already gate through `canon gate run`'s shipped-references stage, and a second opinion here drifts from it.
- Add or propose a pattern-matched check for the `.claude/context/` case. `src/shipped/references.ts`'s own doc comment records why that form stays a semantic read, and building the pattern anyway is the CLI scan the operator declined on 2026-09-05.
- Write the `canon-allow-reference` marker over a real citation to silence this skill. The marker records an illustration, and writing it over a defect hides the defect from the next reader of the same line.

## Guards

- Skip a line already carrying `canon-allow-reference` for another form, since `isMarked` mutes the whole line and a second finding under the same marker restates a call already made.
- Read `598-authoring-layout.md`'s "## What a shipped body may assume about its checkout" section before the first invocation in a session. It states both halves this skill checks, and the rule can move without this file changing.

## Out of scope

- The four mechanically-gated forms, which `src/shipped/references.ts` and `canon gate run` own
- Where toolkit content is authored and which copy a rule or skill cites, which the rest of `598-authoring-layout.md` states and this skill does not re-derive
- Voice, rhythm, and banned words in the same diff, which `write-human` and `markdown.md` own
