# Internal canvas requirement

## Gap

Without this skill, a session editing canvas code loads `internal-scripts`, which never mentions the canvas, and rediscovers each trap from a failing run. It runs a verb against `.canon/canvas/` and writes into the operator's open canvas, or verifies from captures alone while a shell that builds wrong serves a blank page every capture still passes.

In a browser walk it waits on `networkidle` and hangs on the connection the page holds open. It adds a second write path for a property that skips the stale-address hash check, binds a single-letter key that fires while a field has focus, and names a reference tool in a shipped file.

## Must

- The skill points at `canon/context/features/canvas.md` and `canon canvas --help` rather than restating them
- A verb runs against a provisioned `--root`, and the skill says why
- Property edits have one named writer, and a verb lands before its key binding
- The skill states how the shell is driven in a browser and what a walk waits on

## Must not

- Restate the entry's layout, format, or capture decisions, which the ownership table in `CLAUDE.md` puts in the entry
- Restate a verb's records or refusals, which `canon canvas --help` owns

## Out of scope

- `src/` beyond the canvas, which `internal-scripts` owns
- Drawing on the canvas as an operator or session, which `canvas-board` owns
