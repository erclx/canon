# Rules by kind ledger

The field is interface design by surface kind. The authorities are Practical Typography for reading and the Nielsen Norman Group for wayfinding and command shortcuts.

Impeccable's three mode references sort a surface by what the visitor came to do, and most rows below restate them. Impeccable is a community prompt skill rather than an authority, so each such row is a catalog observation. A House choice row names the failure a routing or contrast bullet prevents.

## Marketing and promotional

| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |

| Composition carries the weight | House choice: a palette round run against a flat composition changes nothing a stranger notices, since section order is what they judge first                                                                                                                                   | 2026-10-24 |

| Low density                    | Catalog observation, [Redesign skill](https://github.com/nxpatterns/claude-taste-skill/blob/main/skills/redesign-skill/SKILL.md): "Dense layouts work for data dashboards, not for marketing pages."                                                                            | 2026-10-24 |
| Every claim names a real thing | Catalog observation, [Impeccable persuade mode](https://github.com/pbakaus/impeccable/blob/main/skill/reference/mode-persuade.md): the opening must "demonstrate something only this product can prove"                                                                         | 2026-10-24 |
