# Design taste skill ledger

The field is visual design judgment. Garrett's planes carry the layer order, NN/g carries redesign, tone, and control consistency, Apple carries motion, and Comeau carries shadow lighting. The ten defaults are catalog observations, as in the `tells.md` ledger, recording model output and never cited as an authority. `## What this delegates` routes, so it takes no table.

No outside authority takes a side on the four grey-box rules, four layer rules, the focus ring lock, or the greenfield mode. Each of those ten rows is a house choice naming the failure it prevents. The row leading story and content cites Garrett for the order and names its in-round half as a house choice.

## The layers, and the order they settle

| Bullet                                 | Source                                                                                                                                                                                                                                                                                                                                  | Read       |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| A higher layer over a broken lower one | [Garrett, The Elements of User Experience, ch. 2](http://www.jjg.net/elements/pdf/elements_ch02.pdf): "the choices available to us on each plane are constrained by the decisions we make about issues on the planes below it"                                                                                                          | 2026-10-24 |
| A lower layer through a finished one   | House choice: a finished palette, type, and imagery hide a weak composition or layout, so the round judges the wrong layer and passes it                                                                                                                                                                                                | 2026-10-24 |
| A round varies one layer               | House choice: a round varying several layers yields a pick that cannot say which difference decided it, so the next round repeats the question                                                                                                                                                                                          | 2026-10-24 |
| Never settle a higher layer first      | [Garrett, The Elements of User Experience, ch. 2](http://www.jjg.net/elements/pdf/elements_ch02.pdf): "Each plane is dependent on the planes below it."                                                                                                                                                                                 | 2026-10-24 |
| Story and content lead, in words       | [Garrett, The Elements of User Experience, ch. 2](http://www.jjg.net/elements/pdf/elements_ch02.pdf): "decisions on the strategy plane will have a sort of "ripple effect" all the way up the chain." Settling them inside the requested round is a house choice, since words drawn as arms give a pick no visual difference to compare | 2026-11-08 |
| Check the layers below the complaint   | [Garrett, The Elements of User Experience, ch. 2](http://www.jjg.net/elements/pdf/elements_ch02.pdf): "When the choices we make don't align with those above and below, projects often derail"                                                                                                                                          | 2026-10-24 |
| The story settles once per page        | [Garrett, The Elements of User Experience, ch. 2](http://www.jjg.net/elements/pdf/elements_ch02.pdf): strategy covers "what the people running the site want to get out of it but what the users want to get out of the site as well"                                                                                                   | 2026-11-08 |
| An arc only where the kind requires it | House choice: an arc demanded of an application surface orders tools as an argument nobody reads, while a marketing page with none orders its claims by template                                                                                                                                                                        | 2026-11-08 |
| Sort a fact by deleting its section    | House choice: a page-wide fact written into each card drifts between sections, so the voice reads differently in the seventh section than in the first                                                                                                                                                                                  | 2026-11-08 |
| One content card per section           | [Garrett, The Elements of User Experience, ch. 2](http://www.jjg.net/elements/pdf/elements_ch02.pdf): "scope takes the form of content requirements: a description of the various content elements that will be required."                                                                                                              | 2026-11-08 |

## Grey-box when judging layers 1 to 4

| Bullet                         | Source                                                                                                                                         | Read       |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Flat neutral blocks            | House choice: a fill, an accent, or an image left in a grey-box pulls the judgment toward a layer the round is not judging                     | 2026-10-24 |
| Real text at real length       | House choice: greeked copy hides the wrapping and overflow that real copy at length produces, so a composition passes and then breaks          | 2026-10-24 |
| FPO at true size               | House choice: an unmarked placeholder region is read as a decided element and ships as one                                                     | 2026-10-24 |
| Return to the finished surface | House choice: a grey-box handed over as the deliverable reads to the operator as unfinished work rather than as the answer to a layer question | 2026-10-24 |
