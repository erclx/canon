# Design references skill ledger

The field is design practice and content licensing. A reference library's own terms carry where copying stops, and the community DESIGN.md collection's license carries what a run may fetch and read. The capture and film steps rest on measurements a groundwork track took against four live sites, so their rows are house choices naming the failure each prevents.

The skill is not a practice skill, so this ledger cites the rules a reader would contest rather than every bullet. Steps that call a verb route to it and take no row.

## What a draft may take

| Bullet                                | Source                                                                                                                                                                   | Read       |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- |
| Take layout, rhythm, and shape        | [Mobbin MCP](https://mobbin.com/mcp): "Do not copy protected designs, branding, text, or assets verbatim."                                                               | 2026-11-08 |
| Never another product's text or marks | [Mobbin MCP](https://mobbin.com/mcp): the same line, read as the boundary a reference library sets for a draft drawn from it                                             | 2026-11-08 |
| Never a value named as a value        | House choice: a draft taking another site's colors, sizes, and fonts ships that site's brand, and a value written into a caption is copied by the next arm that reads it | 2026-11-08 |
| Name the source on every frame        | House choice: a frame with no source on a board of designs reads as a design, so a later round lands a reference in the record as though the project drew it             | 2026-11-08 |

## Capture and film

| Bullet                                  | Source                                                                                                                                                                                                                       | Read       |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| One shot per section                    | House choice: a full-page image of a long site cannot be scanned, and sections cut where a designer would name them came back on Notion, Vercel, and Linear in a groundwork spike                                            | 2026-11-08 |
| Film a scroll rather than trust a still | House choice: a still at one scroll position painted Notion's scroll-linked logo strip over its hero in a groundwork spike, and a filmed scroll showed it where a visitor sees it                                            | 2026-11-08 |
| Hovers at desktop alone                 | House choice: a phone has no hover, and a mobile session reported `(hover: hover)` false in a groundwork spike                                                                                                               | 2026-11-08 |
| The phone width takes `--touch`         | House choice: a probe at 320 with the viewport alone matched `(hover: hover)`, and touch emulation matched `(hover: none)` and `(pointer: coarse)`, while full mobile mode laid out a page with no meta viewport at 980 wide | 2026-11-08 |
| One hover per take                      | House choice: a take refuses whole on one missing target, so a hover picked from a snapshot that misses would otherwise cost every film beside it                                                                            | 2026-11-08 |
| No browser script of its own            | House choice: a fix to how a page is shot lands once in `canon capture` or `canon take` rather than in every session's script                                                                                                | 2026-11-08 |
