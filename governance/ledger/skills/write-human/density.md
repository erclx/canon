# Information density reference ledger

The field is plain-language writing and technical editing. The Google and Microsoft developer style guides and digital.gov's plain-language guide carry the sourced rows. `## Measuring a paragraph` holds prose and no bullet, so it takes no table.

## What to cut

| Bullet                             | Source                                                                                                                                                                                                    | Read       |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| A restatement at another altitude  | [Microsoft, Top 10 tips](https://learn.microsoft.com/en-us/style-guide/top-10-tips-style-voice): "Give customers just enough information to make decisions confidently. Prune every excess word"          | 2026-10-28 |
| A setup clause naming the subject  | [Microsoft, Top 10 tips](https://learn.microsoft.com/en-us/style-guide/top-10-tips-style-voice): "Edit out you can when it isn't necessary. Avoid weak phrasing like there is, there are, and there were" | 2026-10-28 |
| A qualifier changing no truth      | [Microsoft Learn style quick start](https://learn.microsoft.com/en-us/contribute/content/style-quick-start): "Be affirmative and don't use extra words or lots of qualifiers"                             | 2026-10-28 |
| An example repeating the one above | House choice: a second example teaching what the first taught doubles the reading for no new case, and the reader goes looking for the difference                                                         | 2026-10-28 |
| A transition naming the relation   | House choice: a transition such as `Additionally` before an addition restates the relation the sentence order already shows, so it adds a word and no claim                                               | 2026-10-28 |

## What never to cut

| Bullet                             | Source                                                                                                                                                                                                          | Read       |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| The verb                           | [Microsoft Learn style quick start](https://learn.microsoft.com/en-us/contribute/content/style-quick-start): small words "(such as "a," "the," "that," and "is") are crucial for machine translation"           | 2026-10-28 |
| A qualifier that bounds a claim    | [Google style guide, Excessive claims](https://developers.google.com/style/excessive-claims): "avoid superlatives like best, simplest, fastest, never, and always", the claim a dropped bound turns `most` into | 2026-10-28 |
| The source and the date of a claim | House choice: a measurement with no ref or date cannot be re-run, so a later reader cannot tell a current number from a stale one                                                                               | 2026-10-28 |
| The actor                          | [Google style guide, Active voice](https://developers.google.com/style/voice): "Make clear who's performing the action"                                                                                         | 2026-10-28 |

## Keeping a compressed sentence unambiguous

| Bullet                           | Source                                                                                                                                                                                                            | Read       |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Resolve every pronoun            | [Google style guide, Write for a global audience](https://developers.google.com/style/translation): "if a pronoun is ambiguous, then replace it with the appropriate noun"                                        | 2026-10-28 |
| Attach every modifier            | [Google style guide, Write for a global audience](https://developers.google.com/style/translation): "place a word like only immediately before the word or phrase that it relates to"                             | 2026-10-28 |
| Quantify an amount               | [Google style guide, Excessive claims](https://developers.google.com/style/excessive-claims): avoid a statement "about performance or cost that isn't easily verifiable with data that's available to the reader" | 2026-10-28 |
| Split two claims joined by `and` | [digital.gov, Write short sentences](https://digital.gov/guides/plain-language/writing/clear-short): "Break up your idea into parts and make each one the subject of its own sentence"                            | 2026-10-28 |
