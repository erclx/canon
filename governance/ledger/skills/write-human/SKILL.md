# Write human skill ledger

The field is plain-language writing and technical editing. Government plain-language guidance from GOV.UK and digital.gov, the Google and Microsoft developer style guides, and Nielsen Norman Group's reading research carry most rows. Purdue OWL carries the cadence rows, whose thresholds are the toolkit's own.

`## The bans stay in force`, `## Machine tells`, and `## Source material` point elsewhere and hold no bullet, so they take no table. The five ordered steps under `## Revising a passage` each take a row, the way a bullet does.

## What yields and what does not

| Bullet                               | Source                                                                                                                                                                                           | Read       |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- |
| A surface's own voice wins           | House choice: a changelog or commit standard that fixes its own voice would otherwise answer to two authorities, and the session picks whichever it read last                                    | 2026-10-28 |
| The yield covers voice alone         | House choice: a declared warmer voice would otherwise excuse the fragment, the padding, and the tells, which read as defects in every register                                                   | 2026-10-28 |
| Terse reference prose is the default | [Microsoft Learn style quick start](https://learn.microsoft.com/en-us/contribute/content/style-quick-start): "Don't waste words. Be affirmative and don't use extra words or lots of qualifiers" | 2026-10-28 |

## Rhythm

| Bullet                              | Source                                                                                                                                                                                                                                                                | Read       |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Read the paragraph as one block     | House choice: cadence is a property of the run, so an edit made line by line clears each sentence and leaves the paragraph as flat as it was                                                                                                                          | 2026-10-28 |
| Longest and shortest within five    | [Purdue OWL, Sentence variety](https://owl.purdue.edu/owl/general_writing/academic_writing/sentence_variety/index.html): "Too many sentences with the same structure and length can grow monotonous for readers". The five-word spread is the toolkit's own threshold | 2026-10-28 |
| Three alike openings is a pattern   | [Purdue OWL, Sentence variety](https://owl.purdue.edu/owl/general_writing/academic_writing/sentence_variety/index.html): "If too many sentences start with the same word, especially The, It, This, or I, prose can grow tedious for readers"                         | 2026-10-28 |
| Vary the shape, not the word        | [Purdue OWL, Sentence variety](https://owl.purdue.edu/owl/general_writing/academic_writing/sentence_variety/index.html): the monotony it names comes from "the same structure and length", so a new first word over one structure leaves it in place                  | 2026-10-28 |
| Never buy variety with a fragment   | [Microsoft Learn style quick start](https://learn.microsoft.com/en-us/contribute/content/style-quick-start): small words "(such as "a," "the," "that," and "is") are crucial for machine translation. Be sure to include them"                                        | 2026-10-28 |
| A connective for flow, never rhythm | House choice: a connective added to vary cadence names no relation the sentences carry, so it reads as the padding the density rules cut                                                                                                                              | 2026-10-28 |

## Density

| Bullet                          | Source                                                                                                                                                                                           | Read       |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- |
| One claim per sentence          | [digital.gov, Write short sentences](https://digital.gov/guides/plain-language/writing/clear-short): "Express only one idea in each sentence"                                                    | 2026-10-28 |

## Revising a passage

| Bullet                             | Source                                                                                                                                                                             | Read       |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Read the whole passage first       | House choice: an edit made before the whole is read polishes a sentence a later paragraph makes redundant                                                                          | 2026-10-28 |
| Mark lengths and openings          | House choice: the counts the rhythm rules name are invisible until written down, and the flattest run carries most of the uniformity a reader hears                                | 2026-10-28 |
| Cut a sentence adding no claim     | House choice: shortening a sentence that carries no claim leaves the padding in place at a smaller size                                                                            | 2026-10-28 |
| Re-read model text for the tells   | [Wikipedia, Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing): it catalogs patterns model output carries, such as "LLMs overuse the rule of three" | 2026-10-28 |
| Run the audit and rewrite each hit | House choice: a near-synonym swapped for a flagged token clears the scan and keeps the habit, the failure that narrowed the markdown standard to characters                        | 2026-10-28 |
