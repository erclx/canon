# Machine tells reference ledger

The field is plain-language writing and technical editing, narrowed to the patterns editors flag in model-written text. Wikipedia's Signs of AI writing, which the humanizer catalog `adopted.md` names is built on, carries most tells. Every source below was read on 2026-10-28.

The reference states each tell as prose under its own H2, and its one list is `## Contents`, which the audit skips. A table here would count rows against no bullet and fail, so each tell takes a list entry instead.

## Sourced to the catalog of model tells

- Rule of three: [Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing) says "LLMs overuse the rule of three"
- Inline-header lists: the same page says model output "often includes vertical lists formatted in a specific way"
- Closing restatement: the same page names section summaries, which older models "often added" to longer outputs
- Escalating parallel clauses: the same page names negative parallelisms, which read "as though it is clearing up a common misconception"
- Empty superlative frames: the same page says "LLM writing often puffs up the importance of the subject matter"

## Sourced to a style guide

- Synonym cycling: [Google, Write for a global audience](https://developers.google.com/style/translation) says "If you use different names for the same thing", readers "might think you're referring to different concepts"
- Adverb propping: [Google, Excessive claims](https://developers.google.com/style/excessive-claims) rules out a claim "that isn't easily verifiable with data that's available to the reader"
- Passive voice with an unnamed actor: [Google, Active voice](https://developers.google.com/style/voice) says "Make clear who's performing the action"

## House choices

- False ranges: a `from X to Y` over items with no scale claims a coverage the sentence never lists, so a reader cannot check what falls inside
- Question as transition: a question standing between paragraphs delays the answer by one line and adds no claim, the padding the density rules cut
- A colon or comma where the dash was: a session told to drop a banned dash swaps the mark and keeps the join, so the ban clears and the habit stays
