# Teach craft pedagogy ledger

The field is learning science. Each paper row links the PubMed abstract `adopted.md` opened and quotes only that abstract, and the IES practice guide rows quote the guide's PDF.

The reference labels the rest as house judgment, being the ladder, production over selection, the zone of proximal development, and the sourcing rules, so those rows name the failure each prevents. `## Contents` takes no table.

## Fluency is not storage strength

## Retrieval practice

| Bullet                                      | Source                                                                                                                                                                                                     | Read       |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Ask before telling                          | [Kornell, Hays and Bjork 2009, Unsuccessful retrieval attempts](https://pubmed.ncbi.nlm.nih.gov/19586265/): "participants attempted to answer the question before being shown the answer"                  | 2026-10-24 |
| Production over selection                   | House choice: a learner picking from four options can pass on recognition alone, so the lesson reports a retrieval the learner cannot do unprompted                                                        | 2026-10-24 |
| Let the attempt fail before correcting      | [Kornell, Hays and Bjork 2009, Unsuccessful retrieval attempts](https://pubmed.ncbi.nlm.nih.gov/19586265/): "Unsuccessful retrieval attempts enhanced learning with both types of materials"               | 2026-10-24 |
| No cue in the question                      | House choice: a question restating the material can be answered by reading it, so it measures reading and reports memory                                                                                   | 2026-10-24 |
| Which rules rest on Kornell, Hays and Bjork | [Kornell, Hays and Bjork 2009, Unsuccessful retrieval attempts](https://pubmed.ncbi.nlm.nih.gov/19586265/): the read-only condition it beat is one where "the question and answer were presented together" | 2026-10-24 |
| A teach-back block in every lesson          | [Nestojko et al. 2014, Expecting to teach](https://pubmed.ncbi.nlm.nih.gov/24845756/): "Participants expecting to teach produced more complete and better organized free recall of the passage"            | 2026-10-24 |
| Name the explanation's audience             | [Nestojko et al. 2014, Expecting to teach](https://pubmed.ncbi.nlm.nih.gov/24845756/): the gain came to "Participants expecting to teach", against "participants expecting a test"                         | 2026-10-24 |
| Record what the explanation left out        | House choice: a missed production filed apart from a missed selection splits one placement input, so the next session places the learner from half of it                                                   | 2026-10-24 |

## Spacing

| Bullet                                    | Source                                                                                                                                                                                               | Read       |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Revisit once forgetting has begun         | [Pashler et al. 2007, IES practice guide](https://ies.ed.gov/ncee/wwc/Docs/PracticeGuide/20072004.pdf): key content seen on two occasions "separated by a period of several weeks to several months" | 2026-10-24 |
| Widen the gap on a hit, shorten on a miss | House choice: a fixed gap keeps reviewing what the learner holds and leaves what they keep missing to fade between sessions                                                                          | 2026-10-24 |
| Name the revisit in the record            | House choice: a next session with no schedule in the record picks its revisit by guess, and the spacing the ladder sets is lost                                                                      | 2026-10-24 |
| Apply the ladder as written               | House choice: an author told to widen a gap by judgment settles on whatever feels right, so two sessions space one topic differently                                                                 | 2026-10-24 |

## Interleaving

| Bullet                                      | Source                                                                                                                                                                                                                     | Read       |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Mix topics once each has a foothold         | House choice, extending Kornell and Bjork's exemplars to topics: a session finishing one topic before the next never makes the learner work out which approach a problem calls for                                         | 2026-10-24 |
| Keep a mixed set close enough to tell apart | [Kornell and Bjork 2008, Learning concepts and categories](https://pubmed.ncbi.nlm.nih.gov/18578849/): a given artist's paintings "presented consecutively (massed) or interleaved with other artists' paintings (spaced)" | 2026-10-24 |
| Never interleave an unseen topic            | House choice: telling two things apart needs something on each side, so mixing in a topic never taught leaves the learner guessing rather than discriminating                                                              | 2026-10-24 |

## The zone of proximal development

| Bullet                                            | Source                                                                                                                                                            | Read       |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Compute the band from the records                 | House choice: a band taken from the subject's own order teaches the next chapter whatever the learner got wrong last time                                         | 2026-10-24 |
| Target the first thing not done unaided           | House choice: a target picked past the first miss builds on a step the learner cannot yet do, so the support carries the task                                     | 2026-10-24 |
| Withdraw support on success, restore it on a miss | House choice: support left in place after a success carries a task the learner can now do alone, and repeating the lesson on a miss restarts what was nearly held | 2026-10-24 |
| Ask where the records show nothing                | House choice: a guessed starting point misses in both directions, either reviewing what is held or skipping what is not                                           | 2026-10-24 |

## Where difficulty helps and where it hurts

| Bullet                                   | Source                                                                                                                                                                                                                                           | Read       |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- |
| New material in its clearest form        | [Pashler et al. 2007, IES practice guide](https://ies.ed.gov/ncee/wwc/Docs/PracticeGuide/20072004.pdf): students "learn more by alternating between studying examples of worked-out problem solutions and solving similar problems on their own" | 2026-10-24 |
| Add difficulty once practicing           | [Kornell, Hays and Bjork 2009, Unsuccessful retrieval attempts](https://pubmed.ncbi.nlm.nih.gov/19586265/): "Unsuccessful retrieval attempts enhanced learning with both types of materials"                                                     | 2026-10-24 |
| A hard explanation is not a hard problem | House choice: a confusing explanation adds load the learner spends decoding the teacher, so the difficulty teaches nothing about the material                                                                                                    | 2026-10-24 |

## Sourcing

| Bullet                                   | Source                                                                                                                                                  | Read       |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Read the subject from sources first      | House choice: parametric recall is confident where it is wrong, and a learner cannot audit a claim nobody read                                          | 2026-10-24 |
| Mark a claim resting on recall           | House choice: an unmarked recalled claim reads with the authority of a sourced one, so the learner trusts the part most likely to be wrong              | 2026-10-24 |
| A source not opened is a lead            | House choice: a citation to a page nobody read can say the opposite of the claim, and the link makes the claim look checked                             | 2026-10-24 |
| The highest rung covering the claim      | House choice: a claim resting on a tutorial when the owner's docs cover it inherits the tutorial's errors and its age                                   | 2026-10-24 |
| No personal or employer proof            | House choice: one project or one employer's practice stands for a general rule only by accident, so a lesson built on it teaches a local habit as a law | 2026-10-24 |
| Owner documentation or specification     | House choice: the owner's own docs track the current version, so a claim read anywhere lower drifts the first time the subject changes                  | 2026-10-24 |
| A canonical work                         | House choice: a subject nobody owns has no docs to rank first, so the standard text or primary paper is the most checked source left                    | 2026-10-24 |
| Other material, recorded with its reason | House choice: a third-rung source recorded without why no higher rung covers the claim cannot be rechecked when a better source appears                 | 2026-10-24 |
