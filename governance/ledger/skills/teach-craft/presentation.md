# Teach craft presentation ledger

The operator picked most of these rules by eye from lessons drawn on a board, so most rows open `House choice` and name the failure the rule prevents. The two rows resting on research quote Mayer 2023 as read on 2026-11-20 in the University of New Hampshire's hosted PDF.

## Citations

| Bullet                             | Source                                                                                                                                                 | Read       |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- |
| A numbered mark with a section pin | House choice: a bare number sends the learner to a whole work, and an inline link breaks the sentence it sits in, so neither leads to the passage read | 2026-11-20 |
| A Harvard reference list           | House choice: sources run inline at the foot of a lesson read as one paragraph, so a learner cannot match a claim to the work behind it                | 2026-11-20 |

## Figures and density

| Bullet                              | Source                                                                                                                                                                                                                                                                                                                                                                     | Read       |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Prose cut to a caption              | [Mayer 2023, Research-based principles for designing multimedia instruction](https://www.unh.edu/teaching-learning-resource-hub/sites/default/files/media/2023-06/itow-research-based-principles-for-designing-multimedia-instruction-mayer.pdf), UNH copy: "People learn more deeply from a multimedia message when extraneous material is excluded rather than included" | 2026-11-20 |
| A tint or space over a border       | House choice: a border that only decorates adds a line the eye has to cross, and a border removed from a control leaves it unidentifiable, so only the control keeps one                                                                                                                                                                                                   | 2026-11-20 |
| A stacked figure on a narrow screen | House choice: a timeline shrunk to a phone's width fell past reading size, and a sideways scroll hides the part of the figure the caption names                                                                                                                                                                                                                            | 2026-11-20 |

## The callout

| Bullet                         | Source                                                                                                                                                                                                                                                                                                                                                                                                                                               | Read       |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| At most one callout            | [Mayer 2023, Research-based principles for designing multimedia instruction](https://www.unh.edu/teaching-learning-resource-hub/sites/default/files/media/2023-06/itow-research-based-principles-for-designing-multimedia-instruction-mayer.pdf), UNH copy: "cues are added that highlight the organization of the essential material", and the count of one is a house choice, since two callouts leave the learner choosing which is the hard part | 2026-11-20 |
| The callout's color kept apart | House choice: quiz feedback drawn in the callout's yellow made a second callout on every quiz, so the one hard part stopped standing out                                                                                                                                                                                                                                                                                                             | 2026-11-20 |

## Contrast

| Bullet                    | Source                                                                                                                                                        | Read       |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| Measure rather than judge | House choice: a kit's blue judged fine by eye measured 4.03:1 for citation marks and a button's white label, under the 4.5:1 text floor                       | 2026-11-20 |
| Measure in every theme    | House choice: the same button measured 3.1:1 in dark, so a pass in light said nothing about the other theme                                                   | 2026-11-20 |
| An edge against its tint  | House choice: a radio mark in the control-edge grey passed on the page and fell to 2.96:1 on the quiz option's tint, under the 3:1 floor for a control's edge | 2026-11-20 |
