# Tasks rule ledger

The rule is a core rule, so every row is a house choice rather than a citation. Only the trim was decided in the change that wrote this ledger, so the older bullets carry the reason their own text gives, and none carries a date nobody recorded.

## Task files

| Bullet                           | Source                                                                                                                                                                                       | Read    |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| Load task-create before an edit  | House choice: the skill carries the layout, filenames, format, origin lines, and archiving, so a hand edit without it breaks a field a later reader parses. It beat restating the shape here | Unknown |
| Report an unresolved task-create | House choice: a project with governance and no plugin holds the rule and lacks the skill, and a silent skip reads as a load that happened. It beat proceeding on recall                      | Unknown |
| Follow the board shape           | House choice: the readiness groups and row order live in the skill, so a second copy here drifts. It beat spelling the groups in the rule                                                    | Unknown |
| Follow the decline shape         | House choice: a task decided against needs the record the skill carries, or the decision is lost. It beat deleting the file                                                                  | Unknown |
