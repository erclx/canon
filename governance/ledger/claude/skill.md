# Skill rule ledger

The rule is a core rule, so every row is a house choice rather than a citation. Only the trim was decided in the change that wrote this ledger, so the older bullets carry the reason their own text gives, and none carries a date nobody recorded. The trim cut the bullet carrying the third creation-time question into `REQUIREMENT.md`, since `create-skill` owns that step.

## Skill files

| Bullet                                 | Source                                                                                                                                                                                       | Read    |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| Load create-skill before an edit       | House choice: the skill carries the skill structure, the requirement shape, and the path rules, so a hand edit without it breaks a shape later audits read. It beat restating the shape here | Unknown |
| Report an unresolved create-skill      | House choice: a project with governance and no plugin holds the rule and lacks the skill, and a silent skip reads as a load that happened. It beat proceeding on recall                      | Unknown |
| Answer the two creation-time questions | House choice: a skill drafted without them lands with no reason to exist, whoever wrote it. It beat trusting the drafter to ask unprompted                                                   | Unknown |
| Re-read an edited skill body           | House choice: a session holds the body it first invoked, so a later invoke runs the old text. It beat assuming the harness reloads an edited body                                            | Unknown |
| Distrust a resolved path as currency   | House choice: a path resolving shows the file exists and not that the held body matches it. It beat reading a resolved path as proof the body is current                                     | Unknown |
