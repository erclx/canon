# Accessibility rule ledger

The field is web accessibility, and the authority is the W3C, through WCAG 2.2 and its Understanding documents, the WAI tutorials, and the ARIA notes. The keyboard and focus half of the old rule moved to `keyboard.md`, whose ledger records those bullets.

## Semantics

| Bullet                                    | Source                                                                                                                                                                                                                                                                                    | Read                 |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| Native `<button>` or `<a>` over a `<div>` | [Using ARIA, first rule](https://www.w3.org/TR/using-aria/): "If you can use a native HTML element or attribute with the semantics and behavior you require already built in", use it "instead of re-purposing an element and adding an ARIA role"                                        | 2026-10-18           |
| Attribute spelling per syntax             | [React common components](https://react.dev/reference/react-dom/components/common): the DOM prop is `tabIndex`, "A number. Overrides the default Tab button behavior", where HTML spells it `tabindex`                                                                                    | 2026-10-18, React 19 |
| Role and synchronized state               | [Understanding Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html): "the name and role can be programmatically determined" and "notification of changes to these items is available to user agents"                                                      | 2026-10-18, WCAG 2.2 |
| Name for a control with no visible text   | [Understanding Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html): every user interface component's "name and role can be programmatically determined"                                                                                                  | 2026-10-18, WCAG 2.2 |
| Name contains the visible label           | [Understanding Label in Name](https://www.w3.org/WAI/WCAG22/Understanding/label-in-name.html): "the name contains the text that is presented visually", and the start position is "A best practice". "People who operate with voice interaction use the visible labels in their commands" | 2026-10-23, WCAG 2.2 |

## Text alternatives

| Bullet                                     | Source                                                                                                                                                                                                                                                           | Read       |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| `alt` on every image, empty for decoration | [Decorative images](https://www.w3.org/WAI/tutorials/images/decorative/): "a null (empty) alt text should be provided ( alt="" ) so that they can be ignored by assistive technologies"                                                                          | 2026-10-18 |
| Meaning or action, not appearance          | [Functional images](https://www.w3.org/WAI/tutorials/images/functional/): the text "should convey the action that will be initiated (the purpose of the image), rather than a description of the image", so "print this page" rather than "(image of a) printer" | 2026-10-18 |

## Contrast and color

| Bullet                          | Source                                                                                                                                                                                                                                             | Read                 |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| 3:1 for boundaries and graphics | [Understanding Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html): "Ensure meaningful visual cues achieve 3:1 against the background"                                                                          | 2026-10-18, WCAG 2.2 |
| 4.5:1 for text                  | [Understanding Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): "The visual presentation of text and images of text has a contrast ratio of at least 4.5:1", with "Large-scale text" at 3:1                 | 2026-10-23, WCAG 2.2 |
| Color never the only carrier    | [Understanding Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html): "Color is not used as the only visual means of conveying information, indicating an action, prompting a response, or distinguishing a visual element" | 2026-10-18, WCAG 2.2 |

## Reflow

| Bullet                                 | Source                                                                                                                                                                                                                                                                                            | Read                 |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| Reflow at 320                          | [Understanding Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html): "without requiring scrolling in two dimensions" at "a width equivalent to 320 CSS pixels", "Except for parts of the content which require two-dimensional layout", such as "maps and diagrams" and "data tables" | 2026-10-18, WCAG 2.2 |
| 320 is 1280 at 400 percent             | [Understanding Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html): "320 CSS pixels is equivalent to a starting viewport width of 1280 CSS pixels wide at 400% zoom"                                                                                                                 | 2026-10-18, WCAG 2.2 |
| The same floor beside resizable chrome | House choice: a panel widened to 480 in a 768 window leaves 288 for the content, under the floor at a window width the criterion passes                                                                                                                                                           | 2026-10-18           |

## Declined

Every bullet the rewrite removed or reshaped, grouped by why.

### Moved to `keyboard.md`

- Moved the focus styles, keyboard model, pointer targets, composite widgets, and focus management H2s to `keyboard.md`, whose ledger records each of those bullets.

### Merged or reworded

- Merged "a `<div>` with a click handler requires a role, a tab index, and keyboard handlers" into the native element bullet, which states the same choice from the other side.
- Merged "set role on custom controls" and "synchronize state attributes with visual state" into one bullet, since both rest on the same success criterion.
- Merged "describe the content or function, not its appearance" and "alt text for functional images should describe the action" into one bullet.
- Shortened the reflow criterion bullet and its 1280 equivalence to fit the 200 character limit, keeping the criterion's exceptions.
- Shortened the resizable chrome bullet and moved its worked example into this ledger's row, since it explained rather than directed.
