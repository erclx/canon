# Teach workspace requirement

## Gap

Without this skill, a session asked to teach answers in the conversation, so everything dies with it. It teaches from recall, picks topics from the subject's order rather than the learner's errors, and asks nothing about what they know. A structure lesson points at a diagram and ships none.

A worked-through page and a looked-up page have different lifetimes, and merging them yields disposable material kept or durable material carrying a quiz. Opened by bare path, a lesson renders unstyled. A workspace resolved against the current directory forks per worktree, and the editing tools refuse a main-root write from one.

## Must

- Hold the workspace at the main worktree root, name the write route from a linked worktree, and route edits to an existing workspace file through a verb that resolves the root
- Ask the learner's starting point, research from sources chosen by the teach standard's ladder, and place each lesson from the learning records
- Split the output by lifetime into lessons and reference pages, record the wrong answer itself rather than a count, and decide each lesson's figure before its body
- Hand the learner a link to the workspace in a real browser on every run, read back from the verb that served it
- Propose each durable page's destination by who owns its subject, wait for the operator, and hand the page off through a named file a branch lands and deletes

## Must not

- Teach from recall without saying which claims rest on it
- Write to a destination surface outside the fold mode, or overwrite a file a promotion block routes to
- Promote a lesson at any age, since it is generated markup carrying a quiz
- Open a second workspace on a covered subject, or renumber anything
- Scaffold a wiki folder the project never chose

## Out of scope

- What the verbs do internally, which the `canon teach` CLI domain owns
- What a lesson renders as and how its quiz behaves, which the lesson-craft reference and the rendering layer own
- Firing on a description match, since opening a workspace is the learner's call
