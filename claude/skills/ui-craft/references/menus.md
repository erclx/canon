# Menus standards

## Context menus

- Offer a context menu on an item a person selects and acts on when it carries two or more actions, and give every item of that kind the same menu.
- Never make a context menu the only path to an action. Put each row's action in the main interface too, since the menu stays hidden until opened.
- Open the context menu on Shift+F10 from the focused item, and move through it by the APG menu pattern.
- Open the same menu on touch and hold wherever the surface takes touch.
