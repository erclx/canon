# Contrast arm

Read before writing the arms of a round declared at composition. A round whose arms all share the skill's restraint cannot show whether restraint is what the operator wants, so one arm steps outside it.

Composition is the only layer this reaches, since story and content settle in words and a read never names either as the layer its arms vary.

## Drawing it

- Grey-box it with the rest of the set, so it carries no accent color and no imagery, per `design-taste`
- Make it bolder in what a grey box still shows, being density, section weight, and how much each section pictures
- Label it `contrast arm` in its frame, since it breaks the one-property rule and the operator reads it as a different question
- Keep it the one arm past the five-arm cap, so the round still says which single property decided the rest

## Where it never goes

A round at layout or later, such as a palette round, takes no contrast arm. Those rounds hold composition fixed, and an arm that breaks it answers a question the round was not asked.

## Reporting it

Say whether the contrast arm won when reporting the pick. A win says restraint was the wrong default for this surface, and a loss says the restrained arms were what the operator wanted.
