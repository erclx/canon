# Teach craft requirement

## Gap

Without this skill, a session asked to teach explains and calls a smooth reply a lesson. It teaches from recall, picks topics from the subject's order rather than the learner's errors, and asks nothing about what they know.

Its quizzes leak the answer through option length or position, and nothing tests the learner later, so fluency passes for retention. It picks content with no goal, explains in prose alone, and leaves where a lesson lands to chance. Each lesson it draws looks different from the last, so a course never reads as one.

## Must

- Carry retrieval, spacing, interleaving, and placement as rules a session applies before picking what to teach next
- Carry planning, explaining, and presenting as rules for any surface, pick the board or a standalone page by whether a board exists, and ship one look for both as a kit folder holding no lesson
- Ask the learner's starting point and read the subject from sources, saying which claims rest on recall
- State quiz design that leaks no answer, pair a quiz with a teach-back, and hold that the wrong answer itself is what the next session places from
- Cite an opened source in the ledger for every kept rule, or label it house judgment with the reason it stays, then close on excuses, red flags, and a checklist

## Must not

- Name a verb, a markup contract, or a stylesheet in a reference, since the rules hold on any surface and the look ships apart from them in the kit folder
- Refuse a lesson for want of a board
- Fire on a request to answer one question
- Go unloaded when a session teaches across exchanges, since a craft body only its author types reaches no lesson

## Out of scope

- The board's verbs and a frame's markup, which belong to Frameboard
