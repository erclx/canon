# Teach craft requirement

## Gap

Without this skill, a session asked to teach explains and calls a smooth reply a lesson. It teaches from recall, picks topics from the subject's order rather than the learner's errors, and asks nothing about what they know.

Its quizzes leak the answer through option length or position, and nothing tests the learner later, so fluency passes for retention.

## Must

- Carry retrieval, spacing, interleaving, and placement as rules a session applies before picking what to teach next
- Ask the learner's starting point and read the subject from sources, saying which claims rest on recall
- State quiz design that leaks no answer, and pair a quiz with a teach-back
- Hold that the wrong answer itself is what the next session places from
- Cite an opened source in the ledger for every kept rule, or label it house judgment with the reason it stays, then close on excuses, red flags, and a checklist

## Must not

- Name a verb, a folder, a markup contract, or a stylesheet, since the skill produces nothing of its own
- Fire on a request to answer one question
- Go unloaded when a session teaches across exchanges, since a craft body only its author types reaches no lesson

## Out of scope

- Where a lesson is stored or how it renders, which belongs to whatever surface the session writes to
