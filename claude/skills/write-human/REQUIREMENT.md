# Write human requirement

## Gap

Without this skill, a session is graded on the words it avoids and never on how the prose reads. The banned characters ship as data a command reads. The voice half sits in a standard nothing opens, so a clean audit passes prose that reads machine-written.

Terse sessions return uniform fragments, each sentence near the same length and opening alike. Rule-of-three and synonym cycling survive any scan because each is a shape, not a token. External catalogs also ban terms this corpus uses heavily, and a session without a stated position rewrites them or ignores the item.

## Must

- Arrive attached to the writing through the path-scoped markdown rule, rather than waiting to be consulted
- State cadence as something to measure, with a sentence-length spread and a repeated-opening count, and ban the fragment trade by name
- Name the machine tells a scan cannot reach behind a stated trigger, and carry marketing words and vague qualifiers as word-choice guidance
- Point at the banned characters rather than restating them, since they ship as package data and a second copy drifts
- Record which external patterns were adopted or declined with the measurement behind each, and yield voice to a surface that states its own

## Must not

- Restate the banned characters, at any length or as an example set
- Present the word guidance as a gate, or restate it on a second surface
- Claim the cadence failure is closed, since nothing measures finished output against these rules yet
- Rewrite a term the corpus already uses because an external source bans it, without the count and a recorded position
- Grow a second voice register inside this body

## Out of scope

- The banned characters, which `markdown-craft` points at and `canon markdown audit` gates
- Markdown mechanics, being headings, lists, code spans, punctuation, and file references, which `markdown-craft` owns
- What voice a given surface declares, which the standard governing that surface owns
- Spelling, which a project's spell checker owns
- Measuring whether finished output followed these rules, which no check owns yet
