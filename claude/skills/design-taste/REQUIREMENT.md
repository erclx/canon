# Design taste requirement

## Gap

Without this skill, a design round cannot declare what it varies. Rounds change palette on a page whose defect sits at composition, and nothing visibly changes. An instruction to name the layer has no catalog behind it, so it gets skipped. Sections are judged alone, and a redesign renames what something outside depends on.

The output has no standard of quality either. A model with no stated direction draws the population average, which satisfies every craft rule and still reads templated. The external catalogs are pinned to one stack, so a session handed one adopts a stack the project does not use or silently drops the item.

## Must

- A declared read naming the kind, the audience, the constraint, the layer, and an existing surface's mode lands in the output before any candidate
- The layers settle in a stated order, a round varies one, a complaint is worked at the lowest layer it reaches, and grey-boxing is announced
- What stays constant across a whole surface is named, and so is what cannot change silently on one that already exists
- The machine defaults are a catalog of shapes with replacements, read on a stated trigger, and a final filter traces each item to a stated rule
- A record names which external patterns were adopted and which declined, and an uncovered kind gets the body's rules and a stated absence

## Must not

- Name a framework, a library, or an icon set as a default, or ship a frozen corpus of palettes, pairings, or examples
- Admit a rule an unguided model already gets right, another surface owns, a threshold settles, or no single line could violate
- Restate the correctness floor or the banned characters, or trade accessibility and the state set against an aesthetic preference
- Express intensity as a numeric scale, or claim a round follows these rules when nothing measures it
- Be reached only by an author typing its name, since `pick-by-eye`'s declared read is the intended caller

## Out of scope

- Accessibility, keyboard interaction, state coverage, forms, and rendered copy, which the `a11y`, `keyboard`, `ux-completeness`, `forms`, and `copy` rules own
- The candidate loop and the pick, which `pick-by-eye` owns
- The shape of the project's design document, which `design-record`'s design reference governs
- Prose on the surface being designed, which `write-human` and `markdown-craft` own
