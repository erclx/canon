# Search craft requirement

## Gap

A session reaching outside the project runs one generic `WebSearch` and takes what ranks highest. Open results skew to third-party pages, two summaries of the same query can disagree on a fact, and an advocacy source can lean the answer. Scoped to authorities the session names itself, the same query returns primary sources.

Access is a second gap a session cannot derive. Some sites refuse a fetch and others have no free route, while `plan-groundwork` and `write-doc` require an outside source and give no route to one. A quote drafted from recall is a third, since it runs no search and reads as exact while its wording or attribution is wrong.

## Must

- Name the field before a query is written, and derive its authorities from the kind of body the field trusts
- Run the query scoped to those authorities and open beside it, prefer the scoped result on a conflict and say so, and check a scoped result's domain before citing it
- Prefer a public API over a fetched page where one exists, and keep an access note grown from failures a session hit, dated by the commit that adds each line
- Quote a source only from a page or ledger row read in the session, with a quoting trigger in the description that reaches a session running no search
- Stop for the operator before a paid or logged-in route, and close with the practice skill's excuses, red flags, checklist, and the sources adopted and declined with the reason for each

## Must not

- Name a site as the destination for a category of question, outside an example marked as an illustration of deriving one
- Ship code, since access code a session needs repeatedly becomes a `canon` verb
- Suggest scraping behind a login or a paywall

## Out of scope

- The form a citation takes, which the procedure writing it owns
- Sourcing a Claude Code subject, which `write-doc` owns through its wiki sourcing step
- Image generation, which makes a picture rather than finding a source
- Loading on every web search rather than a research-shaped request, which a hook matching `WebSearch` owns
