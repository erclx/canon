# Session worktree requirement

## Gap

Without this skill, a hand-picked name matches no plan, and the entry tool's `worktree-<name>` branch breaks the slug the ship chain reads and carries no type `git-pr` accepts. Entry's bare flag in the shared config strands the main checkout, and a rename onto an existing branch destroys work. A submodule reads as the project.

The fresh tree carries no dependencies and its derived port stays invisible, and nothing says so. A main-root write from a linked worktree or a background session meets a refusal pointing at a copy nobody reads, and each skill writing there carried its own diverging route around it.

## Must

- The name comes from the caller, then the plan matched to the branch, through ordered sources, previewed with its source and sanitized to what the entry tool accepts
- The created branch is renamed to `<type>/<name>`, the type taken from the plan's `canon tasks plan-branch` record or `feat`, and the bare flag is read and repaired on both sides of entry
- The target branch and directory are tested before entry, so a collision stops without building a worktree
- One line reports whether the tree carries its dependencies, or has no manifest, and another reports the derived port offset
- The route each kind of main-root write takes is stated once, being a heredoc for a create, a `canon` verb for an edit, and `rm` or `mv` for a delete or move

## Must not

- Install dependencies, since entering to read is as common as entering to run
- Pick between plans, or enter on a name inferred from session context, without asking
- Enter from a linked worktree or a submodule checkout, or overwrite a branch or directory carrying the target name
- Rename a branch entered by path, or invoke the exit path
- Enter or run a guard for a session that loaded the skill to route a main-root write

## Out of scope

- Listing, cleaning up, or rotating worktrees, which `git-worktree` owns
- What runs inside the entered worktree, which the calling skill owns, apart from the main-root write route
