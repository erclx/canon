# Design board

Generated by `canon design board` (`src/design/board.ts`) into a gitignored record folder, opened with `canon serve`. Reads from a caller-resolved `--root`, defaulting to the main worktree. The surfaces panel's landing-page half and the whole components panel render only when that root is this toolkit's own checkout, since both read this repository's own build output.

- Components panel content is generated by `web/gallery-src/pages/index.astro`, cited rather than duplicated here: it renders every component under `web/src/components/` in a labeled section, naming `panel-group` and `panel-row` as unrendered since both take required props with no defaults.
- Tokens panel content is cited rather than duplicated: it is `canon design render`'s own output, documented in `canon/wireframes/landing-page.md`'s sibling `design.md` reference rather than here.

## Behavior

- The pill nav is fixed to the top of the viewport rather than scrolling with the page, so it stays reachable from any panel.
- The nav highlights the link for whichever section fills the most of the viewport as the visitor scrolls, the same largest-intersection-ratio rule `landing-page.md`'s own pill uses.
- The theme toggle swaps a sun icon for a moon icon depending on the active theme, matches `TEACH_CHROME`'s icon-swap convention, and persists the choice in `localStorage` under `board-theme` so a reload keeps the visitor's last pick.
- Each panel embeds its own document by `<iframe>` rather than inlining markup, so a stale iframe never blocks the shell around it from rendering.
