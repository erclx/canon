Trying it

canon expects someone who already knows Claude Code well. It runs on Linux and macOS, and the CLI needs Bun.

claude plugin marketplace add https://github.com/erclx/canonclaude plugin install canon@canonbun install --global @erclx/canon

Then open a project in Claude Code and run /canon:target-setup. It reads the stack, shows what it will lay down, and writes nothing until you say yes. The workflow guide takes it from there.
