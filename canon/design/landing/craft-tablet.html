loads before a new function or module

When no next change can be named, write the plainest code that passes, since a shape built for an unnamed change is a guess.

Google, What to look for in a code review

solve the problem they know needs to be solved now, not the problem that the developer speculates might need to be solved in the future

loads before writing a test

Write the lower test when a higher one catches a break no lower test did.

Ham Vocke, The Practical Test Pyramid

Push your tests as far down the test pyramid as you can

loads before shaping a flag, output, or format

Treat ordering, timing, default values, and the exact text of an error as observable.

Software Engineering at Google, chapter 1

all observable behaviors of your system will be depended on by somebody
