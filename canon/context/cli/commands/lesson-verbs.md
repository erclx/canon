# Lesson verbs

- A verb exists where an instruction to the model would reproduce a defect the instruction already failed to prevent. `canon teach lesson` draws quiz option order rather than telling a session to vary it, because an author varying position by judgment settles on the first slot. It writes nothing: it reports the numbered path the lesson takes, the shared stylesheet with whether the file is on disk, the mission's success lines, and one draw per question. Reporting the stylesheet rather than writing it is what keeps the second lesson in a workspace from discarding what the first one put there.
- `canon teach nav` extends the same principle to a whole page's chrome, splicing the header, breadcrumb, jump menus, and behavior scripts from four marker comment pairs a session leaves empty rather than composing them by hand, which is the judgment that let three hand-authored pages drift out of step with each other. A lesson missing a marker pair is refused by name rather than guessed at, and the root listing and every contents page rewrite from the same read.
- A page behavior a stylesheet can carry ships as CSS spliced into the lesson rather than as an injected script. `canon teach nav` gates a quiz on `:has()` over the radio inputs each question is written from, hiding every question that follows one holding no checked input and hiding feedback until its own question is answered, all inside `@supports selector(:has(*))` so an engine without `:has()` renders every question rather than a stepper showing nothing. Feedback never shows unconditionally outside that wrapper, since the rule outranks `.fb { display: none }` on every engine and would reveal feedback in the button-shape lessons the retired script still drives. The block is spliced after the workspace stylesheet so it wins the cascade at equal specificity, and it hides and shows and sets nothing else, which leaves layout and appearance to the workspace. One detector on `<button class="opt"` decides both regions rather than the scripts one alone, since the stepper's rules match a button question that can never hold a checked radio: a lesson given both mechanisms hides every question past the first for good and outranks the class `QUIZ_SCRIPT` reveals feedback with. The question gate takes the general sibling combinator rather than the adjacent one, which selects the same set for a conforming quiz and is what keeps the gate from resting on a markup contract nothing checks, since the adjacent one matches nothing the moment anything sits between two questions and shows every later one at once.
- A drawn order reports the position it produced alongside the permutation. A caller handed only the permutation derives the answer index itself, which is a second place the same fact can be got wrong, so `orderQuiz` returns both and no caller computes either.
- `src/teach/html/` carries the JSX-to-string factory the lesson body renders through, no React and no build step, and `src/teach/components/` carries the components a lesson composes. `src/teach/components/lesson.test.tsx` composes the components directly as JSX and asserts the rendered string, writing no file. The committed fixture workspace at `examples/teach/00-fixture/` sits outside `.canon/teach/`. `teachDir` in `src/teach/workspace.ts` takes a root already named `teach` as the teach folder itself rather than wrapping it in `recordDir`, which is what lets `canon teach nav 00-fixture --root examples/teach` reach the fixture's workspace verbs the same as any workspace under `.canon/teach/`. `listSlugs` in `src/teach/workspace.ts` keeps only folders named `NN-<topic>`, so a sibling such as `examples/teach/evidence/` is neither listed nor given a contents page by `nav`. A workspace with no `MISSION.md` still lists and draws as a disabled `Stub` row, which `examples/teach/02-unopened/` exists to show.
- `canon teach render` (`src/teach/render.ts`) is the one verb that reaches the component layer, taking no topic and no `--root` since it reads nothing off a workspace. It renders a JSON array of `heading`, `paragraph`, `list`, `refs`, and `raw` blocks from stdin through the four components, refusing `bad-input` by block index on an unrecognized type or a field of the wrong shape for its type. `raw` passes its `html` through unescaped for content the four cannot express, which is the shape the quiz and teach-back markup travel in, carried as the array's last `raw` block, followed only by `refs`. A paragraph's `cites` resolve against the one `refs` block in a second pass after every block renders, so a cite with no reference, a cite on a lede, or a second `refs` block refuses by the offending block's index rather than leaving a dead anchor. Cites stay off the lede because `extractLessonMeta` reads the lede back through `stripTags`, which would keep a marker's digit on the contents page. A reference `url` must parse as `http:` or `https:`, since attribute escaping does not stop a `javascript:` href. Two tests exercise the components, and they differ on the entry point: `lesson.test.tsx` composes them directly as JSX, and `render.test.ts` reaches them through `renderLessonBody`, the block renderer behind this verb. Nothing spawns the verb itself.
- The factory's `jsx()` and every component return the same branded `RawMarkup` value the escape hatch uses rather than a plain string. A component nesting another component's output as `{children}` would otherwise escape it a second time, since a plain string returned from a nested call reads exactly like author text. One brand for both is what lets composition work without double-escaping, and `render()` unwraps to a plain string only at the point a caller writes the result to disk.
- The brand's exemption from escaping is scoped to element content and does not extend to an attribute value. `renderAttribute` escapes a `RawMarkup` value the same as any other string, since a value carrying already-rendered markup is never itself markup once it sits inside a quoted attribute, and treating it as such let a double quote in either an explicit `raw()` call or an ordinary component's output close the attribute early.
