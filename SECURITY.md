# Security policy

## Reporting a vulnerability

Report a vulnerability through GitHub's private vulnerability reporting. Open the repository's Security tab and choose Report a vulnerability. Please do not open a public issue for it.

A report is easiest to act on when it carries:

- What is affected: the command, skill, or file, and the version
- Steps that reproduce it
- What an attacker gains from it

Canon runs locally and ships configs, rules, and skills, so a report about a seed or a rule that weakens a target project's own security is in scope.
