## Reporting a vulnerability

Report it privately through GitHub's [private vulnerability reporting](https://github.com/<owner>/<repo>/security/advisories/new). Do not open a public issue for it.

Include the version, your OS, and the steps that reproduce the problem. You get a reply in the advisory thread.

## Supported versions

Only the latest release receives fixes.
